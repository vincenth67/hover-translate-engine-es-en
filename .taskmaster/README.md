# Taskmaster Project Tasks

This folder contains Taskmaster (ATM) task definitions for the hover-translate-engine-es-en project.

## Main Tasks

- **Build Engine Bundle**: Build the main engine bundle and copy WASM/MJS files to dist/wasm/.
- **Verify WASM/MJS Assets**: Ensure required WASM/MJS files are present for the engine to function.
- **Run Unit Tests**: Run Jest unit tests using the CDN for WASM/MJS.
- **Manual Integration Test (Offscreen Loader)**: Open offscreen.html in Chrome and check the console for engine initialization and translation.
- **Update README Documentation**: Document development, production, and testing workflows for contributors and users.

Task definitions are stored as individual YAML files in this folder.
